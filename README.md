# فكرة في — منصة إنشاء المحتوى وربط Meta

مشروع ويب عربي RTL مبني باستخدام Node.js وExpress. تتضمن هذه النسخة تكامل OAuth فعليًا مع Meta، وعرض صفحات Facebook التي يوافق المستخدم على مشاركتها، واكتشاف حساب Instagram الاحترافي المرتبط بالصفحة، وإرسال منشورات عبر Meta Graph API.

## ما يعمل في هذه النسخة

- تسجيل دخول إداري بكلمة مرور محفوظة في متغيرات بيئة الخادم.
- ربط حساب Meta من خلال OAuth مع التحقق من `state`.
- جلب صفحات Facebook المصرح بها، وتخزين رموز الوصول مشفرة بـ AES-256-GCM.
- نشر نص/رابط أو صورة أو فيديو إلى Facebook Page باستخدام رابط HTTPS عام.
- نشر صورة أو Reel إلى حساب Instagram احترافي مرتبط بصفحة Facebook، باستخدام رابط HTTPS عام.
- واجهة عربية لإدارة الربط واختيار الصفحة وكتابة المحتوى وتنفيذ النشر.
- إنشاء نصوص فيديو عبر OpenAI أو Gemini بعد إضافة المفتاح من الإعدادات.

## قبل النشر

**هذا المشروع جاهز للرفع كخدمة Node.js، لكن التشغيل الفعلي يتطلب إعداد بيانات Meta وموافقة الصلاحيات.** لا يمكن تضمين App Secret أو مفاتيحك في ملف ZIP.

### متغيرات البيئة المطلوبة

اضبط القيم في إعدادات الاستضافة (ولا ترفع ملف `.env`):

- `NODE_ENV=production`
- `DEMO_MODE=false`
- `ADMIN_PASSWORD` كلمة مرور قوية وفريدة للوحة التحكم.
- `SESSION_SECRET` سر عشوائي طويل.
- `SETTINGS_ENCRYPTION_KEY` سر عشوائي مستقل بطول 32 حرفًا على الأقل.
- `DATA_DIR=/var/data` أو مجلد دائم قابل للكتابة.
- `META_APP_ID` رقم تطبيق Meta.
- `META_APP_SECRET` سر تطبيق Meta.
- `OAUTH_CALLBACK_BASE_URL` أصل الموقع فقط، مثل `https://your-app.onrender.com`، دون مسار أو `/` في النهاية.
- `META_GRAPH_VERSION=v23.0` (يمكن تغييره حسب إصدار Graph API المتاح في تطبيقك).

### إعداد Meta Developers

1. أضف منتج Facebook Login إلى تطبيق Meta واضبط تسجيل الدخول عبر الويب.
2. أضف Redirect URI التالي في إعدادات OAuth، مع استبدال النطاق بنطاق موقعك الفعلي:
   `https://YOUR-DOMAIN/api/meta/callback`
3. اطلب الصلاحيات التي تحتاجها الوظائف، ومنها بحسب حالة التطبيق: `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`, `instagram_basic`, `instagram_content_publish`.
4. تأكد أن المستخدم لديه صلاحية إدارة الصفحة، وأن Instagram حساب احترافي مربوط بصفحة Facebook عند النشر على Instagram.
5. اختبر التطبيق بحسابات وأصول مسموح بها ضمن أدوار التطبيق. النشر للمستخدمين الخارجيين قد يتطلب App Review والتحقق التجاري ووضع Live.

## الرفع الموصى به: Render

المشروع يستخدم جلسات Express وملفًا مشفرًا لحفظ رموز Meta، لذلك يحتاج استضافة Node.js بتخزين دائم؛ لا ترفع هذه النسخة كما هي إلى بيئة Serverless لا تحفظ الجلسات والملفات بين الطلبات.

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. في Render اختر **New + → Blueprint** ثم اربط المستودع الذي يحتوي `render.yaml`.
3. أنشئ الخدمة وأدخل `META_APP_ID` و`META_APP_SECRET` و`OAUTH_CALLBACK_BASE_URL` عند الطلب. اضبط `OAUTH_CALLBACK_BASE_URL` على عنوان الخدمة النهائي.
4. بعد ظهور عنوان الخدمة، ارجع إلى Meta Developers وأضف عنوان الرجوع الكامل `https://عنوان-موقعك/api/meta/callback`.
5. افتح الموقع، سجّل الدخول بكلمة مرور `ADMIN_PASSWORD` التي ضبطتها، ثم ادخل «ربط الحسابات» واضغط «ربط حساب Meta».
6. اختر صفحة، واختبر النشر أولًا بمحتوى تجريبي على صفحة تملكها.

يمكن تشغيله محليًا باستخدام Node.js 20 أو أحدث:

```bash
npm install
cp .env.example .env
npm start
```

قبل التشغيل المحلي، غيّر الأسرار الوهمية في `.env` واضبط `OAUTH_CALLBACK_BASE_URL` بما يناسب عنوانك المحلي عند اختبار OAuth.

## حدود واضحة لهذه النسخة

- لوحة الإحصائيات والمنشورات في الصفحة الرئيسية ما زالت أمثلة توضيحية وليست أرقامًا مسترجعة من Meta.
- إنشاء فيديو كامل بالذكاء الاصطناعي غير مفعّل؛ إنشاء النص متاح عبر OpenAI/Gemini بعد ضبط المفاتيح.
- الجدولة التلقائية الدائمة، وسحب التحليلات الحقيقية، وإدارة/الرد على التعليقات ليست مفعّلة بعد.
- نشر Instagram يتطلب رابط صورة أو فيديو عامًا يمكن لخوادم Meta جلبه. لا يرفع هذا الإصدار ملفًا محليًا إلى تخزين عام نيابة عنك.
- قبول النشر يعتمد على صلاحيات التطبيق، نوع الحساب، إعدادات Meta، والمراجعة المطلوبة. لا يوجد ضمان للموافقة بمجرد رفع المشروع.

## ملفات مهمة

- `server.js`: الخادم ومسارات OAuth والنشر.
- `public/`: واجهة المنصة.
- `.env.example`: أسماء متغيرات البيئة دون أسرار فعلية.
- `render.yaml`: إعداد مبدئي للنشر على Render.
- `docs/API.md`: توثيق المسارات.
