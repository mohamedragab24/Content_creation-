# فيديو فلو — لوحة إدارة المحتوى

لوحة عربية باتجاه RTL لتخطيط صناعة الفيديوهات ومتابعة منشورات وحسابات التواصل. المشروع يعمل بـ **Node.js + Express**، ويتضمن واجهة تفاعلية ونقاط API أولية ووصلًا فعليًا لتوليد النصوص عبر OpenAI أو Gemini بعد إضافة المفتاح. مفاتيح مزودي الخدمة التي تُحفظ من الإعدادات تُشفّر على الخادم باستخدام AES-256-GCM.

## تشغيل سريع

1. ثبّت Node.js 20 أو أحدث.
2. فكّ ضغط الحزمة، وافتح الطرفية داخل مجلد `vidflow`.
3. نفّذ `cp .env.example .env`.
4. للتجربة المحلية، اترك `DEMO_MODE=true`، ثم نفّذ:

```bash
npm install
npm start
```

5. افتح `http://localhost:3000`.

## إعداد الإنتاج قبل الرفع

في لوحة متغيرات البيئة لدى Render / Railway / VPS / الاستضافة التي تدعم Node.js، عيّن على الأقل:

- `NODE_ENV=production`
- `DEMO_MODE=false`
- `ADMIN_PASSWORD` كلمة مرور قوية وفريدة
- `SESSION_SECRET` سلسلة عشوائية طويلة
- `SETTINGS_ENCRYPTION_KEY` سر عشوائي مستقل بطول 32 حرفًا أو أكثر
- `DATA_DIR` مجلدًا دائمًا قابلًا للكتابة، مثل `/var/lib/vidflow/data`
- `PORT` تتركه للاستضافة أو تستخدم `3000`

ارفع ملفات المشروع دون `node_modules`، ثم شغّل `npm install` و`npm start`، أو ابنِ الحاوية باستخدام Dockerfile المرفق. افحص `GET /api/health` للتأكد من الجاهزية. إن كانت الاستضافة تعيد تشغيل الحاوية أو تستخدم أكثر من نسخة، اربط تخزينًا دائمًا لمجلد `DATA_DIR` أو استبدل تخزين الأسرار بقاعدة بيانات/خدمة أسرار مشتركة.

**لا ترفع `.env` ولا تشارك مفاتيح API.** غيّر القيم التجريبية قبل أي نشر عام. استخدم HTTPS. وضع العرض التوضيحي للقراءة فقط للمفاتيح؛ لا تحفظ أسرارًا فيه.

## ما الذي يعمل الآن؟

- لوحة إحصائيات وبيانات معاينة عربية تجريبية.
- تصفح عناصر القائمة، البحث، نافذة إنشاء فيديو، وفلاتر واجهة أساسية.
- REST API للصحة، الإحصائيات، إعدادات المزودين، تسجيل دخول إداري بسيط، وإنشاء نص فيديو عبر OpenAI/Gemini عند إعداد المفاتيح.
- حفظ مفاتيح مزود AI المشفرة في ملف بيانات الخادم، مع عدم إرجاع المفتاح إلى المتصفح.

## ما الذي يحتاج بيانات واعتمادات قبل أن يعمل فعليًا؟

- ربط Facebook وInstagram وTikTok وYouTube يحتاج إنشاء تطبيق OAuth لكل منصة، ضبط Redirect URI ونطاقات/صلاحيات API، مراجعة المنصة أحيانًا، ثم استكمال معالجات التفويض والرموز في `src/adapters/`. أزرار الربط والبيانات المعروضة في لوحة التحكم نموذج واجهة وليست تسجيل دخول اجتماعيًا فعليًا.
- توليد الفيديو يتطلب اختيار مزود فيديو محدد ومفتاحه؛ المسار `/api/videos/generate` يوضح موضع الإضافة ويرجع رسالة عدم إعداد حتى تنفيذ adapter.
- النشر التلقائي والجدولة والرد الفعلي على التعليقات تتطلب APIs/OAuth وموافقات المنصات، وجدولة مهام دائمة وقاعدة بيانات. لا تنفذ الحزمة إرسال منشورات أو تعليقات حقيقية الآن.
- Manus يتطلب نقطة API مناسبة للمشروع/الحساب؛ يتم إعدادها بعد تحديد الخدمة وصلاحيات الوصول المتاحة.

لذلك الحزمة **جاهزة لرفع تطبيق Node.js وتشغيل واجهته**، لكنها ليست تكاملًا إنتاجيًا مكتملًا بمنصات التواصل قبل توفير واعتماد APIs لكل منصة.

## ملفات أساسية

- `server.js`: Express، الجلسات ونقاط API.
- `public/`: واجهة الموقع وأصول الصور.
- `.env.example`: قائمة الإعدادات المطلوبة دون أسرار.
- `docs/API.md`: المسارات ومخطط الإضافات.
- `Dockerfile`: تشغيل حاوية.
