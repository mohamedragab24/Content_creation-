# تطبيق سوقنا للبائع

تطبيق Flutter/Dart عربي RTL لمؤشرات المتجر والمنتجات والطلبات. الوصول يتطلب دور بائع فعالًا؛ طلبات تسجيل البائعين الجديدة تنتظر موافقة الإدارة.

```sh
flutter create --platforms=android,ios .
flutter pub get
flutter run --dart-define=API_BASE_URL=https://your-api.example.com/api
```

حساب البائع التجريبي في وضع demo: `seller@souqna.demo` وكلمة المرور `SouqnaDemo1!`. غيّر بيانات المعاينة قبل الإنتاج. لا تتضمن النسخة ملفات بناء APK أو IPA.
